## Things I've built

**[ArgusVision](https://github.com/Ahmadhassan30/ArgusVision)** &nbsp;·&nbsp; Two neural networks argue over a skin-lesion image, and a third model settles the argument. Uncertainty-aware medical AI.<br>
<sub>`PyTorch` `FastAPI` `Next.js` `LightGBM`</sub>

**[Aether](https://github.com/Ahmadhassan30/Aether)** &nbsp;·&nbsp; A C compiler framework in Rust, built so every transformation between program representations is traceable.<br>
<sub>`Rust`</sub>

**[Anemo](https://github.com/Ahmadhassan30/Anemo)** &nbsp;·&nbsp; Turns a lecture into an animated explainer, deterministically, without a single video-generation model.<br>
<sub>`Python` `TypeScript` `agents`</sub>

**[Morpheus](https://github.com/Ahmadhassan30/Morpheus)** &nbsp;·&nbsp; Sketch a website on paper, snap a photo, get working Next.js + Tailwind back.<br>
<sub>`TypeScript` `LangChain` `RAG` `vision LLM`</sub>

**[Harmony](https://github.com/Ahmadhassan30/Harmony)** &nbsp;·&nbsp; Drop in any track and get its BPM, key and scale, with several detection algorithms voting on the answer.<br>
<sub>`Python` `TypeScript` `audio`</sub>

## Research interests

- **Computational neuroscience:** computational models of the brain, and what they can teach machines
- **Resilient multi-agent reasoning:** coordination under uncertainty, long-context memory, changing course when wrong
- **Emergent alignment:** the quiet preferences and biases instruction-tuned models pick up that benchmarks miss
- **Retrieval past naive RAG:** knowledge graphs + dense vectors + tool outputs, so retrieval can reason
- **Literature as reasoning:** stories are compressed causal reasoning, so I read them as research &nbsp;→&nbsp; [recommend me a book](https://github.com/Ahmadhassan30/Ahmadhassan30/issues/new?title=Book%20recommendation%3A%20&body=Title%3A%0AAuthor%3A%0AWhy%20I%27d%20like%20it%3A%0A)
